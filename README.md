# 🛡️ CyberShield — Network Threat Monitoring Dashboard

Real-time cybersecurity threat monitoring dashboard built with React.js and Spring Boot.

## 🚀 Tech Stack
- **Frontend:** React.js, Recharts, React Router DOM
- **Backend:** Java Spring Boot, REST APIs
- **Database:** MySQL
- **DevOps:** Docker, AWS EC2

## ✨ Features
- Live threat feed with color-coded severity badges
- Interactive charts — Bar, Line, Pie (Recharts)
- Filterable and searchable threat log table
- Auto-refresh every 5 seconds
- Dark cybersecurity themed UI

## 🖥️ Run Locally
git clone https://github.com/thanupolisetty/cybershield-dashboard.git
cd cybershield-dashboard
npm install
npm start
